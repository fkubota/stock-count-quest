# 在庫カウントクエスト / STOCK COUNT QUEST

> 👉 **[ここをクリックして遊ぶ](https://fkubota.github.io/stock-count-quest/)**

飲食店の在庫カウント（棚の在庫を数えて記録する作業）が、
なぜ現場でめんどくさがられるのかを、体で分かってもらうためのドット絵ブラウザゲームです。

インストールも設定も要りません。上のリンクをクリックすれば始まります。

---

## 何をするゲーム？

あなたは飲食店のスタッフです。出勤すると、在庫カウントの依頼が届いています。

```
在庫カウントが必要な食材/備品が 4 件あります。
現在の在庫数を確認し、本日の納品を含めた在庫数を入力してください。
```

これを片付けないと発注に進めません。やることは単純です。

1. パソコンまで行って、何を数えるのか確認する
2. 厨房とバックヤードを歩きまわって、それを探す
3. 目で数えて、覚える
4. パソコンまで戻って入力する

……単純なはずなのですが、たぶん思ったとおりにはいきません。

## 遊び方

| キー | すること |
|---|---|
| ↑ ↓ ← → | 移動・カーソル・数値の増減 |
| ↑ ↓ ← →（保管場所） | カーソルを動かす（棚の段をまたげます） |
| Z | 調べる・開ける・**奥を みる** |
| C | **持つ・はかりに のせる**（戻す・おろすも C） |
| X | 戻る |
| Enter | 確定 |
| B | 音のオン・オフ（BGMと効果音） |

画面を一度クリックしてからキーを押してください。

## ルールは3つだけ

1. **何を数えるかは、パソコンの前でしか分からない。** 出勤したときは、依頼が来たことしか知らされません
2. **どこに何があるかは、誰も教えてくれない。** 店じゅうを歩いて、自分で開けて探します
3. **数えるのは自分の目と頭だけ。** 歩いて戻って、思い出して入力します

## 遊ぶたびに店が変わります

品目も、数も、置き場所も、毎回つくり直されます。

- 置いてあるもののうち、**今日数えるのは4つだけ**。残りは全部ただの在庫です
- **同じものが2か所に分かれて置いてあることがあります。** 両方の合計を入れないと正解になりません
- 棚は段になっていて、ものは不ぞろいに積んであります
- **目で数えるものは、奥のものが手前に半分ほど隠れます。** 野菜の山積みも、冷凍庫の袋も、
  パックもそうです。カーソルを合わせると `Z` で「奥を みる」が出るので、持ち上げて確認します。
  そのままでも数えられる置きかたになっていますが、見落とすと1個ずれます
- **野菜は数えられます。でも、4件のうち1件は「玉」ではなく「g」で聞かれます。**
  見た目では分かりません。パソコンの前に立って、はじめて気づきます。
  数えた玉数は何の役にも立たないので、取りに戻ることになります。
  野菜は `C` でいつでも抱えて運べます（何玉あっても一度に持てます）。
  **持てるかどうかで今日の単位は分かりません。** 単位が「玉」の日に運んでも、ただの無駄骨です。
  はかりに載せれば重さが出ますが、1玉ずつ重さが違うので、
  数えて掛け算しても当たりません
- **使いかけは、同じ品目につき必ず1つだけ**です。残りは未開封で満杯です
- 液体は目盛りのない瓶に入っています。`4L` や `1.8L` の瓶のうち1本だけが半端な量です。
  いっぱいの位置だけ破線で示してあるので、そこからの目分量で読みます。
  入力が `0.5L` 刻みなので、**答えも必ず 0.5L 刻み**です。そこまで読めれば当たります
- 箱は開けるまで中身が分かりません。1箱だけ開けかけです
- **グラムで量るものは、ふた付きのタッパーに入っています。** 中が見えないので、
  はかり台まで運ばないと何も分かりません。置き場所は冷蔵庫と作業台です。
  容器ごと `C` で持ち、4つまで一度に運べます。**戻せるのは取った場所だけ**です。
  容器に書いてある数字は**中身の量ではなく、空っぽの容器そのものの重さ**です
- はかり台では、持っているものから `C` で**載せるものを選べます**。はかりは容器ごと量るので、
  出るのは「容器こみの重さ」です。**空の容器の合計を引いて**はじめて中身の量が分かります。
  混ぜて載せると合計しか出ません
- **作業台には必ず寸胴の仕掛品があります**（カレー、ライス、だし など）。
  バットも寸胴も、はかり台まで運んで量ります。**寸胴は重いので手が2つぶん塞がります**
- 冷凍庫のものは霜で真っ白です

さらに、

- **「本日2袋 納品予定」を足さないと正解にならない。** まだ開けていない段ボールの分です
- **正直に数えると警告が出ることがある。** 「想定在庫から大きく離れます」
- **「数えなおす」を選ぶと、また歩いて見にいくことになる。** この往復が「まあいいか」を生みます
- **システムの想定が、たまたま合っていることもあります。** だから人はスキップします

最後のリザルトに **スキップ率** が出ます。
一度も数字を動かさずに確定した割合です。だいたい、思っていたより高い数字が出ます。
この数字をみんなで眺めるのが、このゲームの目的です。

## 音

BGMと効果音が鳴ります。音声ファイルは置いていません。全部その場で合成しています。
`B` で音楽と効果音をまとめてオン・オフできます。

## 技術的なこと

- `index.html` 1枚だけ。外部ライブラリ・CDN・ビルド・サーバーすべて不要
- ドット絵は画像ファイルではなくコード内でCanvasに描いています
- favicon（コック帽）も外部ファイルにせず、data URI として埋め込んでいます
- 文字だけはドット絵化せず、くっきり描いています（読めないと意味がないので）
- 記録はブラウザの localStorage に保存します

### ローカルで開く場合

`index.html` をダウンロードしてダブルクリックすれば、それだけで動きます。
ただしこの開き方（`file://`）だと、ブラウザによっては記録が保存されません。
その場合は上のURLから遊んでください。
