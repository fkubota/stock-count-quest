# 在庫カウントクエスト / STOCK COUNT QUEST

> 👉 **[ここをクリックして遊ぶ](https://fkubota.github.io/stock-count-quest/)**

飲食店の在庫カウント（棚の在庫を数えて記録する作業）が、
なぜ現場でめんどくさがられるのかを、体で分かってもらうためのドット絵ブラウザゲームです。

インストールも設定も要りません。上のリンクをクリックすれば始まります。

---

## 何をするゲーム？

あなたは飲食店のスタッフです。出勤すると、在庫カウントの依頼が届いています。

```
在庫カウントが必要な食材/備品が 5 件あります。
現在の在庫数を確認し、本日の納品を含めた在庫数を入力してください。
```

これを片付けないと発注に進めません。やることは単純です。

1. パソコンまで行って、何を数えるのか確認する
2. 厨房とバックヤードを歩いて、それを探す
3. 目で数える
4. パソコンまで戻って入力する

……単純なはずなのですが、たぶん思ったとおりにはいきません。

## 遊び方

| キー | すること |
|---|---|
| ↑ ↓ ← → | 移動・カーソル・数値の増減 |
| Z | 調べる・決定・箱を開ける |
| X | 戻る |
| Enter | 確定 |
| N（タイトル画面） | 仕事中の通知をオンにする |

画面を一度クリックしてからキーを押してください。

## ルールは3つだけ

1. **何を数えるかは、パソコンの前でしか分からない。** 出勤画面では件数すら教えてくれません
2. **どこに何があるかは、誰も教えてくれない。** 自分で開けて探します
3. **数える道具はない。メモも取れない。** 目で数えて、自分の頭で覚えて、歩いて戻って入力します

## 仕込んであるめんどくささ

遊んでいて「それはズルい」と思うところが、たぶん現場で起きていることです。

| 場所 | 数えるもの | いやなところ |
|---|---|---|
| 冷蔵庫 | 袋もの | 不ぞろいに並んでいて、目で数えると間違える |
| 冷蔵庫 | 液体 | 瓶に目盛りがない。「だいたい半分」を L に直す |
| 常温だな | 箱の中身 | 開けるまで分からない。空の箱も混ざっている |
| 作業台 | 仕込みずみのもの | バットと寸胴で入れ物が違う。換算が要る |
| バックヤード | 冷凍もの | 霜で真っ白。袋の境目が見えない |

さらに、

- **「本日2袋 納品予定」を足さないと正解にならない。** まだ開けていない段ボールの分です
- **正直に数えると警告が出る。** 「想定在庫から大きく離れます」。自分のほうを疑い始めます
- **「数えなおす」を選ぶと、また歩いて見にいくことになる。** この往復が「まあいいか」を生みます

最後のリザルトに **スキップ率** が出ます。
一度も数字を動かさずに確定した割合です。だいたい、思っていたより高い数字が出ます。
この数字をみんなで眺めるのが、このゲームの目的です。

## 仕事中の通知

タイトル画面で `N` を押して通知を許可すると、**開いてから1分後に催促が届きます**。

ブラウザの通知なので、**タブを開いている間だけ**届きます。
閉じている間に通知を飛ばすことは、サーバーのない静的ページにはできません。

## 技術的なこと

- `index.html` 1枚だけ。外部ライブラリ・CDN・ビルド・サーバーすべて不要
- ドット絵は画像ファイルではなくコード内でCanvasに描いています
- 文字だけはドット絵化せず、くっきり描いています（読めないと意味がないので）
- 記録はブラウザの localStorage に保存します

### ローカルで開く場合

`index.html` をダウンロードしてダブルクリックすれば、それだけで動きます。
ただしこの開き方（`file://`）だと、ブラウザによっては記録が保存されず、通知も届きません。
その場合は上のURLから遊んでください。
