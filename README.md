# 在庫カウントクエスト / STOCK COUNT QUEST

> 👉 **[ここをクリックして遊ぶ](https://fkubota.github.io/stock-count-quest/)**

飲食店の在庫カウント（棚の在庫を数えて記録する作業）が、
なぜ現場でめんどくさがられるのかを、体で分かってもらうためのドット絵ブラウザゲームです。

インストールも設定も要りません。上のリンクをクリックすれば始まります。

---

## 何をするゲーム？

あなたは飲食店のスタッフです。出勤すると、在庫カウントの依頼が届いています。

```
在庫カウントが必要な食材/備品が 3 件あります。
現在の在庫数を確認し、本日の納品を含めた在庫数を入力してください。
```

これを片付けないと発注に進めません。やることは単純です。

1. 厨房を歩いて冷蔵庫まで行く
2. 冷蔵庫を開けて、言われた食材を数える
3. 少し離れたパソコンまで歩く
4. 画面に、数えた在庫数を入力する

……単純なはずなのですが、たぶん思ったとおりにはいきません。

## 遊び方

| キー | すること |
|---|---|
| ↑ ↓ ← → | 移動・カーソル・数値の増減 |
| Z | 調べる・決定・1つ数える |
| X | 戻る |
| ↓（カウント中） | しゃがんで棚の奥を見る |
| Enter | 確定 |
| M | 手持ちメモを開く |

画面を一度クリックしてからキーを押してください。

## 仕込んであるめんどくささ

遊んでいて「それはズルい」と思うところが、たぶん現場で起きていることです。

- **棚の奥に在庫が隠れている** — しゃがまないと見えないので、普通に数えると足りません
- **「本日2袋 納品予定」を足さないと正解にならない** — まだ開けていない段ボールの分です
- **数える場所とパソコンが離れている** — 歩いているうちに、覚えた数字があいまいになります
- **正直に数えると警告が出る** — 「想定在庫から大きく離れます」。自分のほうを疑い始めます
- **「数えなおす」を選ぶと冷蔵庫まで戻される** — この往復のコストが「まあいいか」を生みます

最後のリザルトに **スキップ率** が出ます。
一度も数字を動かさずに確定した割合です。だいたい、思っていたより高い数字が出ます。
この数字をみんなで眺めるのが、このゲームの目的です。

## 技術的なこと

- `index.html` 1枚だけ。外部ライブラリ・CDN・ビルド・サーバーすべて不要
- ドット絵は画像ファイルではなくコード内でCanvasに描いています
- 文字だけはドット絵化せず、くっきり描いています（読めないと意味がないので）
- 記録はブラウザの localStorage に保存します

### ローカルで開く場合

`index.html` をダウンロードしてダブルクリックすれば、それだけで動きます。
ただしこの開き方（`file://`）だと、ブラウザによっては記録が保存されません。
記録を残したい場合は上のURLから遊んでください。
